## 🎯 Getting Started

### Quick Start (5 minutes)
```bash
# Backend
cd MobileShop.Api
dotnet restore && dotnet ef database update && dotnet run

# Frontend (new terminal)
cd MobileShop.Web
npm install && npm start
```

**API**: https://localhost:5001
**Frontend**: http://localhost:4200
